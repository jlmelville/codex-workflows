# Sentence-Admission Cases

Use these cases to resolve content-selection boundaries, not as wording
templates.

## Unsupported Contrast

A package plan enumerates dependencies. Saying that it does not predict elapsed
time answers no established reader expectation. Describe what the plan provides
and omit the unsupported contrast.

## Action-Changing Warning

An installer reports missing system libraries but cannot install them. That
limitation belongs because the reader must install the libraries before
retrying. State the consequence and required action together.

## Code Narration And Task Bridges

“The next line runs PCA” merely narrates visible code. “PCA supplies the two
coordinates used by the visualization” can be useful when dimensionality
reduction is incidental setup and visualization is the reader's actual task.

## Surface Fit

A quick-start README normally needs installation, the first successful task,
and recovery from likely failures. Pilot measurements and maintainer validation
commands may remain valuable, but belong in development notes or contributing
guidance unless they change a README reader's decision.

## Arcane Controls

Do not document a sentinel value only because the API accepts it. Include it
when a supported reader task requires the behavior, and explain that task—for
example, disabling cache reuse to test a clean preparation path.
